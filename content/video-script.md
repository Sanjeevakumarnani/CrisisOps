# CrisisOps demo script

**0:00–0:25 — Intro**
Emergency response produces huge amounts of operational information. CrisisOps turns that information into a memory that can be recalled before the next decision.

**0:25–1:00 — Problem**
Show the common operational picture: affected people, open needs, resource capacity, responder presence and blocked routes. Explain that conditions change and previous actions can be forgotten.

**1:00–1:45 — Capture and retain**
Load the response exercise. Open a field event and show location, time, source, needs, resources, responders, transport constraints and attempted actions. Explain that the event is retained as structured operational memory.

**1:45–2:35 — Recall**
Open Memory Review and submit a response plan. Show the generic baseline beside the memory-backed review. Point out recalled history and evidence.

**2:35–3:15 — Reflect**
Show recurring patterns, resource conflicts, transport constraints and unanswered questions. Explain that reflection turns multiple retained events into operational lessons.

**3:15–3:45 — Outcome and learning**
Add or update an event with an outcome. Explain that the result becomes part of the memory available to later decisions.

**3:45–4:00 — Takeaway**
CrisisOps does not replace responders. It gives responders a persistent operational memory so earlier experience is available when it matters.
