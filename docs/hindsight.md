# Hindsight memory design

CrisisOps stores durable response events in the `crisisops-disaster-response-memory` bank. Each event preserves needs, resources, responders, transport constraints, conditions, attempted actions and outcomes.

Before reviewing a proposed response plan, CrisisOps recalls similar situations and uses Hindsight reflection to surface recurring patterns, conflicts, constraints, recommendations and unanswered questions.

The demo also exposes local fallback similarity so the interface remains demonstrable without credentials; the UI clearly labels live Hindsight versus demo mode.
