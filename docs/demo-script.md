# Demo script

1. Open the Common Operational Picture.
2. Load the response exercise and show affected people, open needs, resource capacity, responders and blocked routes.
3. Open a field event to show source, time, location and attempted actions.
4. Submit a response plan.
5. Show the generic baseline beside the memory-backed review.
6. Point to recalled history, recurring patterns, transport constraints and evidence.
7. Add a new event with an outcome and explain that it becomes durable memory for later decisions.
8. Emphasize that CrisisOps supports responders; it does not autonomously dispatch resources.
